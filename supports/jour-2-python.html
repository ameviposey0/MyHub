0:08 · Partie 1 · Pseudo-code

Quatre gestes, dans cet ordre

À dire

Recette de cuisine : l’ordre compte. Pseudo-code = français structuré. Quatre gestes : afficher, déclarer une variable, lire (input), condition. Python reprendra exactement les quatre, dans le même ordre. On ne code pas encore.

Geste 1 · Afficher du texte

À montrer 
DEBUT
  AFFICHER "Bonjour"
  AFFICHER "On commence."
FIN
« Guillemets = texte. Sans guillemets = nom de variable. L’ordre des lignes est l’ordre à l’écran. »

Geste 2 · Déclarer une variable

À dire Déclarer = créer la boîte et lui donner une valeur. ← range. prenom ← "Awa" puis AFFICHER prenom montre le contenu, pas le mot prenom.
À montrer 
prenom ← "Awa"
age ← 20
AFFICHER prenom
AFFICHER age
Noms : pas d’accent, pas d’espace, ne commence pas par un chiffre.

0:08 · Partie 1 · suite

Saisie, puis condition

Geste 3 · LIRE (input)

À montrer 
AFFICHER "Ton prénom ?"
LIRE prenom
AFFICHER "Bonjour"
AFFICHER prenom
« LIRE s’arrête. La valeur n’est plus collée dans la recette. »

Geste 4 · SI / SINON

À dire Feu tricolore. Une branche à la fois. FIN SI ferme. Sans ça, on ne sait plus où ça reprend.
À montrer · 16 puis 20, à voix haute 
DEBUT
  AFFICHER "Ton âge ?"
  LIRE age
  SI age >= 18 ALORS
    AFFICHER "Tu peux voter."
  SINON
    AFFICHER "Pas encore."
  FIN SI
FIN
Ne traduis pas encore en Python.

0:47 · Partie 2 · Python

Les mêmes quatre gestes, dans le même ordre

À dire « Partie réservée à Python. Ce n’est pas un autre cours. On reprend afficher, variable, saisie, condition. Tu traduis, tu ne devines pas. »
À montrer · table, à laisser à l’écran

AFFICHER → print · ← → = · LIRE → input · SI / FIN SI → if: + le retrait.

Geste 1 · même exemple 
print("Bonjour")
print("On commence.")
Casse : print(Bonjour) → lis le NameError.
Geste 2 · même exemple 
prenom = "Awa"
age = 20
print(prenom)
print(age)
« = déclare et range. Ce n’est pas l’égal des maths. »

0:47 · Partie 2 · suite

input, puis if

Geste 3 · même accueil 
prenom = input("Ton prénom ? ")
print("Bonjour")
print(prenom)
« input rend toujours un texte. Pour un âge : int(...). »
Geste 4 · même âge, 16 puis 20 
age = int(input("Ton âge ? "))
if age >= 18:
    print("Tu peux voter.")
else:
    print("Pas encore.")
Enlève l’indentation : lis IndentationError. = range, == pose la question.

1:22 · Mini-projet

decision.py · assez pour payer ?

À dire

Problème du quotidien, pas une page web. Prix, puis l’argent en poche. Assez → le reste. Pas assez → ce qui manque. D’abord les commentaires pseudo-code, ensuite le Python.

  • Fichier decision.py.
  • Pseudo-code en # en haut.
  • Deux int(input(...)).
  • if / else : reste ou manque.
  • Deux tests : 1500 / 2000, puis 1500 / 800.
Squelette à taper en live · eux ensuite 
# DEBUT
#   LIRE prix
#   LIRE argent
#   SI argent >= prix ALORS
#     AFFICHER le reste
#   SINON
#     AFFICHER ce qui manque
#   FIN SI
# FIN

prix = int(input("Prix de l'article ? "))
argent = int(input("Tu as combien ? "))

if argent >= prix:
    reste = argent - prix
    print("C'est bon. Il te reste :", reste)
else:
    manque = prix - argent
    print("Pas assez. Il manque :", manque)
Checkpoints 1) Qui a le pseudo-code en commentaires ? 2) Qui a un fichier qui se lance ? 3) Qui a testé les deux cas ? Aide d’abord ceux sans recette écrite.
Blocages decision.py.txt → extensions Windows. python introuvable → online-python.com. Curseur qui clignote → input. ValueError → ils ont tapé un mot au lieu d’un nombre.
