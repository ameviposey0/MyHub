0:08 · Partie 1

Un programme, c’est une recette

À dire

HTML = les murs de la page. Python = la langue des instructions. La recette n’est pas le plat. L’interpréteur, c’est le cuisinier qui lit ligne par ligne. S’il bute, il s’arrête et dit pourquoi.

À montrer · 2 min Tape et lance, lentement : 
print("Bonjour")
print("Je m'appelle Awa")
Puis casse volontairement : print(Bonjour) sans guillemets. Lis le NameError à voix haute : « il cherche une variable Bonjour ».

Variables

À dire

Une variable, c’est une boîte avec une étiquette. Le = range, il n’est pas « égal » comme en maths. print("Bonjour", prenom) : Python va chercher dans la boîte.

À montrer 
prenom = "Awa"
print(prenom)
print("Bonjour", prenom)
Change prenom une fois, relance : toute la suite suit. « C’est pour ça qu’on nomme : on change à un seul endroit. »

Types · 4 minutes, pas un cours université

Texte · str

Guillemets. "20" + "1" → "201".

Entier · int

Sans guillemets. 20 + 1 → 21.

À montrer 
print("20" + "1")
print(20 + 1)
print(int("20") + 1)
Phrase clé : « les guillemets changent le métier de la valeur ».
Noms de variables Pas d’accent (prenom pas prénom), pas d’espace (envie_1), ne commence pas par un chiffre. S’ils demandent les listes : « pas ce soir, trois variables suffisent ».

0:47 · Partie 2

input, puis if

À dire

Jusqu’ici le prénom était collé dans le code. input, c’est le micro : le programme attend. Toujours un texte, même si tu tapes 20. Pour calculer un âge : int(...).

À montrer · tape avec eux 
prenom = input("Ton prénom : ")
print("Bonjour", prenom)
Laisse le curseur clignoter 3 secondes : « il attend. Entrée pour valider. »

if : le feu tricolore

À dire Vert tu avances, rouge tu t’arrêtes. = range, == pose la question. L’indentation, c’est le bloc : ce qui est en retrait appartient au si.
À montrer 
age = int(input("Ton âge : "))
if age >= 18:
    print("Tu peux voter.")
else:
    print("Pas encore.")
Lance une fois avec 16, une fois avec 20. Puis enlève l’indentation sous le if : lis IndentationError à voix haute.
elif, 2 minutes Montre oui / non / autre chose. Ne construis pas un menu à 8 branches. Une décision claire suffit.

À toi · 16 minutes

Trois exercices input / if

2.1 · 5 min · On tape 16 
age = int(input("Âge : "))
if age >= 18:
    print("Majeur")
else:
    print("Mineur")
Corrigé 2.1 Affiche Mineur. 16 n’est pas >= 18. Branche else.
2.2 · 5 min · Répare 
ville = input("Ville : ")
if ville = "Lomé"
print("On est au Togo.")
Corrigé 2.2
  1. = → == (question, pas rangement).
  2. Deux-points après la condition : if ville == "Lomé":
  3. Le print en retrait sous le if.
ville = input("Ville : ")
if ville == "Lomé":
    print("On est au Togo.")
2.3 · 6 min · Accueil qui décide Si le prénom tapé est le leur → « C’est moi ! ». Sinon → « Enchanté, … ».
Corrigé 2.3 · exemple 
prenom = input("Prénom : ")
if prenom == "Awa":
    print("C’est moi !")
else:
    print("Enchanté,", prenom)
Rappelle : la casse compte. awa n’est pas Awa. Si quelqu’un bloque là-dessus : « ce soir on compare tel quel ».

1:22 · Mini-projet

bio.py écrit le texte de la vitrine

À dire

Plus de cours. Fichier vitrine/bio.py. Il demande, il décide si le prénom est vide, il affiche un texte prêt à coller dans index.html. Dépôt MyHub à la fin.

Cahier des charges · non négociable

  • Fichier nommé bio.py.
  • input pour le prénom, la phrase, 3 envies.
  • Si prénom vide → « Il me faut un prénom. »
  • Sinon, affichage propre : prénom, phrase, liste des 3 envies.
Squelette à taper en live · puis ils adaptent 
prenom = input("Ton prénom : ")

if prenom == "":
    print("Il me faut un prénom.")
else:
    phrase = input("Une phrase sur toi : ")
    envie_1 = input("Envie 1 : ")
    envie_2 = input("Envie 2 : ")
    envie_3 = input("Envie 3 : ")

    print()
    print("--- Texte pour ta vitrine ---")
    print(prenom)
    print(phrase)
    print("Cette semaine je veux :")
    print("-", envie_1)
    print("-", envie_2)
    print("-", envie_3)
Checkpoints toutes les 8 minutes 1) Qui a un fichier .py qui se lance ? 2) Qui a le input prénom ? 3) Qui voit les 3 envies à l’écran ? Aide d’abord ceux sans fichier. Recoller dans le HTML est un bonus, pas un critère de validation.
