0:08 · Partie 1

Un algorithme, c’est une recette

À dire

Recette de cuisine : l’ordre compte. L’ordinateur n’a pas d’intention. Pseudo-code = français structuré, lisible par un humain. Programme = la même recette pour la machine. On ne code pas avant la recette.

À montrer · au tableau / éditeur, encore sans Python 
DEBUT
  AFFICHER "Bonjour"
  AFFICHER "On commence."
FIN
« Deux lignes, dans cet ordre. Si j’inverse, le message change. L’ordre est le métier. »

Les mots du soir

DEBUT FIN · AFFICHER · LIRE · ← · SI ALORS · SINON · FIN SI.

À montrer · variable, puis lecture 
prenom ← "Awa"
AFFICHER prenom
Puis : 
AFFICHER "Ton prénom ?"
LIRE prenom
AFFICHER prenom
« LIRE s’arrête. Comme quelqu’un qui attend que tu parles. »

SI / SINON

À dire Feu tricolore. Une branche à la fois. FIN SI ferme la décision. Sans ça, on ne sait plus où la recette reprend.
À montrer 
DEBUT
  AFFICHER "Ton âge ?"
  LIRE age
  SI age >= 18 ALORS
    AFFICHER "Tu peux voter."
  SINON
    AFFICHER "Pas encore."
  FIN SI
FIN
Parcours à voix haute avec 16, puis avec 20. Ne traduis pas encore en Python.

À toi · 12 minutes · papier ou chat

Trois exercices pseudo-code

Pendant qu’ils cherchent Pas de Python. Pas de corrigé à l’écran. Aide d’abord ceux qui n’ont pas encore numéroté l’exercice 1.1.
1.1 · 4 min · Ordre du thé Verser / attendre que ça bouille / allumer / mettre l’eau / ajouter le sachet.
Corrigé 1.1 1 mettre l’eau · 2 allumer · 3 attendre que ça bouille · 4 verser · 5 ajouter le sachet. (Allumer avant l’eau est discutable : accepte « allumer puis eau » si l’ordre reste logique. L’idée : on ne verse pas avant d’avoir de l’eau chaude.)
1.2 · 4 min · Parapluie SI réponse = oui → parapluie. SINON → pas besoin.
Corrigé 1.2 
DEBUT
  AFFICHER "Est-ce qu'il pleut ?"
  LIRE reponse
  SI reponse = "oui" ALORS
    AFFICHER "Prends le parapluie."
  SINON
    AFFICHER "Pas besoin."
  FIN SI
FIN
1.3 · 4 min · Recette cassée 
DEBUT
  AFFICHER "Ville ?"
  LIRE ville
  SI ville = "Lomé"
    AFFICHER "On est au Togo."
FIN
Corrigé 1.3
  1. Il manque ALORS (et les deux-points plus tard en Python).
  2. Il manque FIN SI avant FIN.
Version propre : SI ville = "Lomé" ALORS … FIN SI … FIN.

0:47 · Partie 2

Python, c’est la traduction

À montrer · table, puis live

AFFICHER → print · ← → = · LIRE → input · SI → if: · SINON → else: · FIN SI → fin du retrait.

À dire Guillemets = texte. Sans guillemets = variable. = range, == pose la question. input rend toujours un texte : pour un prix, int(...).
À montrer · casse volontairement print(Bonjour) → lis le NameError. Puis le couple recette / code de l’âge, côte à côte. Enlève l’indentation sous le if : lis IndentationError.
Côte à côte · à laisser à l’écran 
age = int(input("Ton âge ? "))
if age >= 18:
    print("Majeur")
else:
    print("Mineur")
Lance 16, puis 20. « Même recette qu’avant la pause. Python exécute. »

À toi · 16 minutes

Trois exercices traduction

2.1 · 5 min · Traduis AFFICHER "Ville ?" · LIRE ville · AFFICHER ville
Corrigé 2.1 
ville = input("Ville ? ")
print(ville)
int inutile : une ville n’est pas un nombre.
2.2 · 5 min · On tape 16 Programme majeur / mineur.
Corrigé 2.2 Affiche Mineur. Branche else.
2.3 · 6 min · Répare 
ville = input("Ville : ")
if ville = "Lomé"
print("On est au Togo.")
Corrigé 2.3 ==, deux-points, retrait sous le if. 
ville = input("Ville : ")
if ville == "Lomé":
    print("On est au Togo.")

1:22 · Mini-projet

decision.py · assez pour payer ?

À dire

Problème du quotidien, pas une page web. Prix, puis l’argent en poche. Assez → le reste. Pas assez → ce qui manque. D’abord les commentaires pseudo-code, ensuite le Python.

  • Fichier decision.py.
  • Pseudo-code en # en haut.
  • Deux int(input(...)).
  • if / else : reste ou manque.
  • Deux tests : 1500 / 2000, puis 1500 / 800.
Squelette à taper en live · eux ensuite 
# DEBUT
#   LIRE prix
#   LIRE argent
#   SI argent >= prix ALORS
#     AFFICHER le reste
#   SINON
#     AFFICHER ce qui manque
#   FIN SI
# FIN

prix = int(input("Prix de l'article ? "))
argent = int(input("Tu as combien ? "))

if argent >= prix:
    reste = argent - prix
    print("C'est bon. Il te reste :", reste)
else:
    manque = prix - argent
    print("Pas assez. Il manque :", manque)
Checkpoints 1) Qui a le pseudo-code en commentaires ? 2) Qui a un fichier qui se lance ? 3) Qui a testé les deux cas ? Aide d’abord ceux sans recette écrite.
Blocages decision.py.txt → extensions Windows. python introuvable → online-python.com. Curseur qui clignote → input. ValueError → ils ont tapé un mot au lieu d’un nombre.
