Partie 1 · Pseudo-code

Un algorithme, c’est une recette

Un algorithme, c’est une suite d’étapes claires, dans l’ordre. Le pseudo-code, c’est cette recette écrite en français structuré. Python viendra après, pour la même recette.

Quatre gestes ce soir, toujours dans cet ordre :

  1. Afficher du texte.
  2. Déclarer une variable.
  3. Lire une saisie (input).
  4. Faire une condition.

Chaque programme s’ouvre par DEBUT et se ferme par FIN.

Partie 1 · Pseudo-code · Geste 1

Afficher du texte

AFFICHER montre un message à l’écran. Le texte va entre guillemets. L’ordre des lignes est l’ordre à l’écran. 

DEBUT
  AFFICHER "Bonjour"
  AFFICHER "On commence."
FIN

À l’écran :

Bonjour
On commence.
  • Guillemets = c’est du texte, affiché tel quel.
  • Sans guillemets = c’est le nom d’une variable (geste 2).
  • Chaque AFFICHER passe à la ligne suivante.
Piège AFFICHER Bonjour sans guillemets : la recette cherche une boîte appelée Bonjour. Le texte, lui, vit entre ".

Partie 1 · Pseudo-code · Geste 2

Déclarer une variable

Une variable, c’est une boîte avec un nom. Déclarer, c’est créer la boîte et lui donner une valeur. Le signe ← veut dire « mets ça dans la boîte ». 

DEBUT
  prenom ← "Awa"
  age ← 20
  AFFICHER prenom
  AFFICHER age
FIN

À l’écran : Awa puis 20.

On affiche le contenu de la boîte, pas le mot « prenom ». "Awa" est du texte. 20 est un nombre (pas de guillemets : on pourra calculer avec).

OKPas OKPourquoi
prenomprénomPas d’accent dans le nom.
age2ageNe commence pas par un chiffre.
envie_1envie 1Pas d’espace : utilise _.
À retenir Déclarer = nom + flèche + valeur. Ensuite tu réutilises le nom, sans retaper la valeur.

Partie 1 · Pseudo-code · Geste 3

Lire une saisie (input)

Jusqu’ici, c’est toi qui as collé « Awa » dans la recette. LIRE, c’est l’input : le programme s’arrête et attend que quelqu’un tape une réponse, puis range cette réponse dans une variable. 

DEBUT
  AFFICHER "Ton prénom ?"
  LIRE prenom
  AFFICHER "Bonjour"
  AFFICHER prenom
FIN
  1. On affiche la question.
  2. LIRE prenom déclare (ou remplit) la variable avec ce qui est tapé.
  3. On affiche « Bonjour », puis le contenu de prenom.
À retenir LIRE crée souvent la variable en même temps. La valeur n’est plus collée dans la recette : elle arrive au moment de l’exécution.

Partie 1 · Pseudo-code · Geste 4

Faire une condition

Analogie feu : vert tu avances, rouge tu t’arrêtes. SI pose une question. Une seule branche s’exécute. 

DEBUT
  AFFICHER "Ton âge ?"
  LIRE age
  SI age >= 18 ALORS
    AFFICHER "Tu peux voter."
  SINON
    AFFICHER "Pas encore."
  FIN SI
FIN
MotRôle
SI … ALORSSi c’est vrai, fais ce bloc.
SINONSinon, fais l’autre bloc.
FIN SILa décision est terminée.
>= < =Comparer deux valeurs.

Parcours : si on tape 16 → « Pas encore. » Si on tape 20 → « Tu peux voter. »

À bien verrouiller Ce qui est en retrait sous le SI appartient au « si ». Sans FIN SI, on ne sait plus où la recette reprend.

Partie 2 · Python · Geste 1

Afficher du texte · print

Même exemple qu’en pseudo-code.

Pseudo-code

DEBUT
  AFFICHER "Bonjour"
  AFFICHER "On commence."
FIN

Python

print("Bonjour")
print("On commence.")
  • Les guillemets entourent un texte.
  • Sans guillemets, Python cherche une variable.
  • print(Bonjour) → erreur NameError.

Partie 2 · Python · Geste 2

Déclarer une variable · =

En maths, = veut dire « égal ». En Python, = déclare la boîte et range la valeur. C’est le ← du pseudo-code.

Pseudo-code

prenom ← "Awa"
age ← 20
AFFICHER prenom
AFFICHER age

Python

prenom = "Awa"
age = 20
print(prenom)
print(age)

"20" est du texte. 20 est un nombre. "20" + "1" donne "201". 20 + 1 donne 21.

Partie 2 · Python · Geste 3

Lire une saisie · input

Même accueil qu’en pseudo-code. input = LIRE.

Pseudo-code

AFFICHER "Ton prénom ?"
LIRE prenom
AFFICHER "Bonjour"
AFFICHER prenom

Python

prenom = input("Ton prénom ? ")
print("Bonjour")
print(prenom)
À retenir input rend toujours un texte. Pour une note ou un âge, on convertit : age = int(input("Ton âge ? ")).

Partie 2 · Python · Geste 4

Faire une condition · if / else

Même décision d’âge. Plus de FIN SI : le retrait ferme le bloc.

Pseudo-code

LIRE age
SI age >= 18 ALORS
  AFFICHER "Tu peux voter."
SINON
  AFFICHER "Pas encore."
FIN SI

Python

age = int(input("Ton âge ? "))
if age >= 18:
    print("Tu peux voter.")
else:
    print("Pas encore.")

Les deux-points : ouvrent le bloc. 4 espaces = ce qui appartient au if ou au else. = range. == pose la question « est-ce égal ? ».

ErreurRéflexe
SyntaxErrorParenthèse, deux-points ou guillemet manquant.
NameErrorVariable oubliée, ou texte sans guillemets.
IndentationErrorLe retrait sous le if manque.
ValueErrorint("Awa") : ce n’est pas un nombre.

Partie 3 · Mini-projet

Assez pour payer ?

Un problème du quotidien. D’abord la recette, ensuite le code. Fichier : python/decision.py.

Le problème

On demande le prix d’un article, puis la somme que tu as. Si tu as assez, le programme affiche le reste. Sinon, il affiche ce qui manque.

Étape A · le pseudo-code (non négociable)

Écris-le en commentaires en haut du fichier, avec #.

# DEBUT
#   AFFICHER "Prix de l'article ?"
#   LIRE prix
#   AFFICHER "Tu as combien ?"
#   LIRE argent
#   SI argent >= prix ALORS
#     reste ← argent - prix
#     AFFICHER "C'est bon. Il te reste :"
#     AFFICHER reste
#   SINON
#     manque ← prix - argent
#     AFFICHER "Pas assez. Il manque :"
#     AFFICHER manque
#   FIN SI
# FIN

Étape B · la traduction Python

prix = int(input("Prix de l'article ? "))
argent = int(input("Tu as combien ? "))

if argent >= prix:
    reste = argent - prix
    print("C'est bon. Il te reste :", reste)
else:
    manque = prix - argent
    print("Pas assez. Il manque :", manque)

Cahier des charges

  • Le fichier s’appelle decision.py.
  • Le pseudo-code est en commentaires en haut du fichier.
  • Deux input convertis avec int : prix et argent.
  • Un if / else : assez, ou pas assez.
  • Tu l’as lancé au moins deux fois : une fois « assez », une fois « pas assez ».
Exemple pour tester Prix 1500, argent 2000 → reste 500. Prix 1500, argent 800 → il manque 700.
