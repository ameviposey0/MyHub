Partie 1 · Cours

1. Un programme, c’est une recette

Hier, tu as écrit du HTML : la structure d’une page. Aujourd’hui, tu écris des instructions : l’ordinateur les lit, dans l’ordre, et les exécute. C’est un programme.

Analogie cuisine : la recette n’est pas le plat. Python, c’est la langue de la recette. L’interpréteur Python, c’est le cuisinier qui lit et exécute, ligne par ligne.

Le fichier

On enregistre le programme dans un fichier qui finit par .py. Exemple : bio.py. C’est du texte, comme index.html hier.

L’exécution

Python lit le fichier du haut vers le bas. S’il bute sur une ligne, il s’arrête et affiche une erreur. Ce n’est pas toi qui es « nul » : c’est la recette qui est floue.

Le premier mot : print

print fait parler l’ordinateur. Il affiche quelque chose à l’écran. Le texte va entre guillemets. 

print("Bonjour")
print("Je m'appelle Awa")

À l’écran, tu vois :

Bonjour
Je m'appelle Awa
  • Les guillemets " ou ' entourent un texte.
  • Sans guillemets, Python cherche un nom (une variable).
  • Chaque print passe à la ligne suivante.
Piège du soir print(Bonjour) sans guillemets → erreur NameError. Python cherche une variable appelée Bonjour. Le texte, lui, vit entre guillemets.

Partie 1 · Cours

2. Une variable, c’est une boîte avec un nom

Au lieu de réécrire « Awa » partout, tu ranges la valeur dans une variable. Tu colles une étiquette sur une boîte. 

prenom = "Awa"
print(prenom)
print("Bonjour", prenom)

À l’écran :

Awa
Bonjour Awa

Le signe = n’est pas « égal » comme en maths. Il range : « mets "Awa" dans la boîte prenom ».

Règles pour nommer

OKPas OKPourquoi
prenomprénomPas d’accent dans le nom.
age2ageNe commence pas par un chiffre.
envie_1envie 1Pas d’espace : utilise _.
messageprintN’écrase pas un mot de Python.
Convention du soir Minuscules, mots collés avec un tiret bas : prenom, phrase, envie_1. Un nom dit ce qu’il y a dans la boîte.

Deux types pour commencer

Texte · str

Entre guillemets. "Awa", "20". On peut coller deux textes avec +.

Nombre entier · int

Sans guillemets. 20, 12. On peut additionner : 20 + 2 donne 22. 

prenom = "Awa"
age = 20
print(prenom + " a " + str(age) + " ans")
print(age + 1)

str(age) transforme le nombre en texte, pour pouvoir le coller. age + 1 calcule : 21.

"20" n’est pas 20 "20" + "1" donne "201" (collage de textes). 20 + 1 donne 21 (calcul). Les guillemets changent le métier de la valeur.

Partie 2 · Cours

3. input : l’ordinateur écoute

Jusqu’ici, c’est toi qui as collé « Awa » dans le code. Avec input, le programme demande et attend que tu tapes une réponse. 

prenom = input("Ton prénom : ")
print("Bonjour", prenom)

L’ordinateur affiche Ton prénom :, tu tapes, tu valides avec Entrée, puis il dit bonjour.

À retenir input rend toujours un texte (str), même si tu tapes 20. Pour calculer avec un âge, tu convertis : age = int(input("Ton âge : ")).

4. if : une décision

Un programme qui fait toujours la même chose, ce n’est pas encore très vivant. if veut dire : « si c’est vrai, fais ceci ». 

age = int(input("Ton âge : "))
if age >= 18:
    print("Tu peux voter.")
else:
    print("Pas encore.")

Analogie feu : vert → tu avances. Rouge → tu t’arrêtes. Le if choisit la branche.

L’indentation, c’est le bloc

En Python, les espaces en début de ligne comptent. Ce qui est en retrait sous le if appartient au « si ». On aligne avec 4 espaces (la touche Tab, souvent).

ComparaisonSens
==Est-ce égal ? (question)
=Range dans la boîte (ordre)
!=Est-ce différent ?
> < >= <=Plus grand / plus petit
= n’est pas == prenom = "Awa" range. prenom == "Awa" pose la question. Si tu écris if prenom = "Awa":, Python refuse.

Un troisième chemin : elif

reponse = input("Tu as déjà codé ? (oui/non) : ")
if reponse == "oui":
    print("Bienvenue, on accélère un peu.")
elif reponse == "non":
    print("Parfait, c’est le public du soir.")
else:
    print("Réponds par oui ou non.")

Les quatre erreurs du soir

Quand Python s’arrête, lis la dernière ligne du message. C’est souvent suffisant.

ErreurÇa veut direRéflexe
SyntaxError La phrase est mal formée : parenthèse, deux-points, guillemet. Compte les ( et les ".
NameError Python ne connaît pas ce nom. Variable oubliée, ou texte sans guillemets.
IndentationError Le retrait sous le if manque ou dépasse. Aligne avec 4 espaces.
ValueError int("Awa") : on ne peut pas transformer ça en nombre. Vérifie ce que tu tapes dans input.

Partie 3 · Mini-projet

Un script écrit le texte de ta vitrine

Hier, tu as tapé le texte à la main dans index.html. Ce soir, Python le compose. Tu le recopieras ensuite dans ta page — même vitrine, autre métier.

Fichier à créer Dans le dossier vitrine : bio.py (pas .txt, pas .html).

Cahier des charges · non négociable

  • Le fichier s’appelle bio.py.
  • Il demande ton prénom avec input.
  • Il demande une phrase sur toi (2 ou 3 phrases collées, ou une seule).
  • Il demande 3 envies pour la semaine.
  • Il affiche un texte propre, prêt à coller dans la vitrine.
  • Si le prénom est vide, il dit « Il me faut un prénom. » et s’arrête.

Modèle à adapter (change Awa)

Tape-le, ne le copie pas en silence. Remplace les exemples par tes réponses en live.

prenom = input("Ton prénom : ")

if prenom == "":
    print("Il me faut un prénom.")
else:
    phrase = input("Une phrase sur toi : ")
    envie_1 = input("Envie 1 : ")
    envie_2 = input("Envie 2 : ")
    envie_3 = input("Envie 3 : ")

    print()
    print("--- Texte pour ta vitrine ---")
    print(prenom)
    print(phrase)
    print("Cette semaine je veux :")
    print("-", envie_1)
    print("-", envie_2)
    print("-", envie_3)
Ensuite, dans index.html Copie le texte affiché : le <h1> reçoit le prénom, le <p> reçoit la phrase, la liste reçoit les 3 envies. Tu n’es pas obligé de tout recoller ce soir : le script qui marche suffit pour valider. Recoller, c’est le bonus.
